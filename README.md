## 🎮 About the Project

**BLOCK GAME** is a recreation of the original **BLOKORZ** game released in 2007.

The main goal of the project was to recreate the original gameplay experience while rebuilding the game using modern development tools and a new technical foundation.
The remaster preserves the original gameplay structure and progression, with the player completing a series of levels from **1 to 100**.
The project was rebuilt from the ground up in **Unity and C#**, including a new UI, save/load functionality and the systems required to recreate the original game experience.

---

## 🧱 Gameplay

The core gameplay remains faithful to the original BLOKORZ.
The player progresses through a sequence of increasingly challenging levels, starting from **Level 1** and continuing all the way to **Level 100**.
Each level is designed around the original gameplay mechanics and progression structure.

# 🕹️ Game Progression

The game consists of **100 playable levels**.

Progression is structured around completing levels in sequence:

```
Level 01
   ↓
Level 02
   ↓
.......
   ↓
Level 99
   ↓
Level 100
```

The save system allows the player's progress through these levels to be preserved between game sessions.

# 🔄 Remaster/Remake Approach

The project was created with the goal of preserving the original gameplay rather than redesigning it.

The core experience remains based on the original **2007 BLOKORZ**, while the underlying implementation was rebuilt using modern development tools.

* Unity engine
* C# implementation
* New UI
* Save / Load system
* Rebuilt game architecture
* Reimplemented gameplay systems

This approach allows the game to retain its original identity while being rebuilt as a modern Unity project.

# 🖥️ UI System

The remaster contains a completely rebuilt UI.

The interface was recreated specifically for the new Unity implementation while maintaining the functionality and structure expected from the original game.

The UI covers areas such as:

* Main Menu
* Level selection / progression
* Gameplay interface

* Save / Load
* Game-related information

---

# 💾 Save / Load System

The project includes a dedicated save/load system for persistent game progress.

The system allows the player to continue their progression after closing and reopening the game.

Saved information can include the player's current progression through the game's level structure.

---

# ⚙️ Settings

The remaster contains a settings system based on the original game's configuration.

The goal was to preserve the same overall settings experience while rebuilding its implementation in Unity.

Settings are integrated into the new UI and can be accessed through the game's menus.

---

# 🔊 Audio

The audio experience follows the original BLOKORZ.

The remaster preserves the role of the original audio within the gameplay experience while integrating it into the new Unity implementation.

Audio is managed independently from the gameplay systems and can be configured through the game's settings.

---

The separation of systems makes it easier to manage the game's 100 levels and extend the project without putting all of the logic into a single system.
